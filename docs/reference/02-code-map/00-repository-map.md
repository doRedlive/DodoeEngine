# 仓库代码地图

## 顶层目录说明

- `engine/`：引擎主目录，包含核心源码、脚本、资源模板与工具
- `engine/src/`：主要 C++ 源码目录
- `engine/external/`：第三方依赖或外部集成内容
- `engine/scripts/`：脚本/资源/开发流程辅助脚本
- `tests/`：测试工程与样例
- `scripts/`：构建、环境准备、辅助脚本
- `docs/`：设计文档、计划与参考
- `build/`：CMake/IDE 生成输出目录
- `bin/`：构建产物或运行时产物目录

## 重点目录说明

### `engine/src/`
- 运行时逻辑、核心模块实现、资源加载、动画、渲染、脚本

### `tests/`
- 功能验证、示例与回归测试

## 代码阅读推荐顺序
1. `engine/src/` 的核心模块
2. `tests/` 中的示例
3. `docs/` 的设计文档
