# Project Reference Index

这个目录是项目文档的统一入口，用来说明仓库的整体结构、关键模块、开发方式以及给 Agent / AI 助手的阅读方式。

## 文档阅读顺序

建议按下面顺序阅读：

1. `01-architecture/00-project-overview.md`
2. `01-architecture/01-system-architecture.md`
3. `02-code-map/00-repository-map.md`
4. `03-development/00-build-and-test.md`
5. `05-agent/agent-reading-guide.md`

## 文档分类

- `01-architecture/`：项目架构、模块关系、运行时流程
- `02-code-map/`：仓库目录与模块职责说明
- `03-development/`：构建、测试、规范
- `05-agent/`：专门给 Agent / AI 助手看的阅读说明

## 维护原则

- 新功能或新模块增加时，应同步补充对应文档
- 文档内容尽量和代码结构保持一致
- 涉及公共接口、模块边界或关键流程的修改，需要更新相关说明
