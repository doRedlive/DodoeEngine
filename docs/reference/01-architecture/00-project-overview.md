# 项目概览

## 项目定位

这个仓库是一个以 C++ 为主的引擎/运行时工程，包含以下几类内容：

- 引擎核心逻辑
- 运行时系统
- 动画与资源相关能力
- 脚本/世界/场景相关机制
- 编辑器、沙盒、测试与构建辅助工具

## 主要目录

- `engine/`：引擎核心实现
- `engine/src/`：主要源码目录
- `engine/scripts/`：脚本与资源相关辅助内容
- `tests/`：测试工程与样例
- `scripts/`：构建、配置、辅助脚本
- `docs/`：项目设计、规范、计划与参考文档

## 代码阅读建议

建议按以下顺序理解项目：
1. `docs/reference/01-architecture/`
2. `engine/src/` 中的核心模块
3. `tests/` 中的使用方式
